  LDAP open on a domain controller — worth checking for anonymous bind  [MEDIUM]
(score 0.9, user_curated)
  An open LDAP port on a DC does NOT by itself mean anonymous bind works — that 
has to actually be tested. When it does work, an unauthenticated query (RootDSE 
namingContexts, or a user dump with -x and no bind DN) is a misconfiguration, 
not a CVE, so searchsploit won't have a matching exploit. If the check below 
succeeds, dump users/groups/computers next and feed the names into AS-REP 
roasting.
  Check with: `ldapsearch -x -H ldap://<target> -s base namingcontexts` — if 
that returns real naming contexts (not an error), THEN try `ldapsearch -x -H 
ldap://<target> -b '<DC=...>' '(objectClass=user)' sAMAccountName` to dump 
users.
